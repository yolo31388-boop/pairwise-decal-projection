# pairwise-decal-projection

弹孔贴花在斜面上缺一块，投影盒没按表面法线扩展，薄墙背面也能看到弹孔；贴花深度测试与不透明物体用同一套，远处出现 z-fighting；贴在蒙皮角色上的贴花按静态位置投影，角色一动弹孔就滑走；角度淡出用点积没 clamp，背面透出黑斑；透明贴花按距离排序，同一面墙上的血迹互相覆盖；多相机分屏共享贴花缓冲，左右眼数量不同；贴花 atlas 采样越界，边缘出现相邻图案；异步生成的贴花在绘制时还没 ready，画面闪烁；贴花法线没转到切线空间，光照方向反了；性能档限制贴花数量，旧贴花直接消失没有淡出。render/decal_projection.py 是核心，tests/test_decal_projection.py 15个红。要修的是：投影盒沿法线扩展；贴花独立深度偏移；蒙皮网格用骨骼变换；角度淡出钳制；透明贴花按层排序；多相机独立缓冲；atlas 加 border；贴花就绪后再提交；法线转切线空间；超限贴花淡出回收。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
